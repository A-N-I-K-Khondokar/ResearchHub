Bengali Handwritten Character Recognition using Deep Learning

group

Anik Khondokar, Mou Tusi

Machine Learning Computer Vision Bengali OCR
history_edu Conference Paper • 2025 • International Conference on Machine Learning (ICML)

Overview

This research addresses the significant challenges in optical character recognition (OCR) for complex scripts by introducing a novel convolutional neural network architecture specifically optimized for Bengali handwritten characters. By leveraging a custom dataset of over 50,000 distinct character variations, the model achieves state-of-the-art accuracy, mitigating common issues related to compound characters and varying stroke densities inherent in cursive Bengali handwriting.
